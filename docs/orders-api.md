# Поведение сервиса заказов

Договорённость о том, что сервис заказов принимает и что отвечает.
Изменяется только через запрос на внесение изменений.

Базовый адрес: `http://localhost:8002` при локальном запуске,
`http://orders:8000` внутри docker compose.

Общие правила:

- Тело запроса и ответа — JSON.
- Дата и время передаются в формате ISO 8601, например `2026-10-22T11:24:29`.

---

## POST /orders — создать заказ

Приходит:

| Поле | Тип | Ограничение |
| --- | --- | --- |
| `account_id` | целое | номер существующего клиента, больше 0 |
| `item` | строка | что заказали, от 1 до 128 символов |
| `quantity` | целое | сколько, не меньше 1 |

Ответ `201` — карточка созданного заказа:

| Поле | Тип |
| --- | --- |
| `id` | целое, присвоенный номер заказа |
| `account_id` | целое |
| `item` | строка |
| `quantity` | целое |
| `created_at` | дата и время создания |

Ошибки:

| Код | Когда |
| --- | --- |
| `422` | нет обязательного поля, неверный тип или `quantity` меньше 1; в ответе указано проблемное поле |
| `404` | клиента с номером `account_id` не существует |
| `503` | сервис клиентов не отвечает (сервис заказов жив, недоступен сосед) |

---

## GET /orders/{id} — получить заказ по номеру

Вместо `{id}` — номер заказа.

Ответ `200` — карточка заказа с теми же полями, что у создания
(`id`, `account_id`, `item`, `quantity`, `created_at`).

Ошибки:

| Код | Когда |
| --- | --- |
| `422` | `id` не является целым числом |
| `404` | заказа с таким номером нет; в ответе указан номер, который искали |

---

## GET /orders?account_id= — список заказов клиента

Параметры строки запроса:

| Параметр | Тип | По умолчанию | Ограничение |
| --- | --- | --- | --- |
| `account_id` | целое | обязательный | номер клиента |
| `limit` | целое | 50 | от 1 до 200 — ограничение размера выдачи |
| `offset` | целое | 0 | от 0 — пропуск первых N заказов |

Ответ `200` — список карточек заказов только этого клиента,
упорядоченный по номеру заказа. Если у клиента нет заказов,
возвращается пустой список `[]` и код 200, а не ошибка.

Ошибки:

| Код | Когда |
| --- | --- |
| `422` | нет `account_id`, или `limit`/`offset` вне границ |
